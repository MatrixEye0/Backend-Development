| JWT                                                   | Session                                       |
| ----------------------------------------------------- | --------------------------------------------- |
| Token-based authentication                            | Session-based authentication                  |
| Server token ki information/validity verify karta hai | Server session ko store karta hai             |
| Usually stateless                                     | Stateful                                      |
| JWT client ke paas hota hai                           | Session data server ke paas hota hai          |
| Scaling relatively easy                               | Session store ko scale/manage karna padta hai |
| Logout/revocation more complicated                    | Logout easy                                   |
| Microservices/API ke liye popular                     | Traditional web apps ke liye very common      |
